Architectural composition (DID work)

portfolio_pyvrp_warm = PyVRP@8s construction → LinUCB-bandit at remaining budget. This is not a new operator; it swaps the warmstart source from auction_gart to PyVRP. At N≥100, the swap flips a −$78 loss vs PyVRP@60 into a +$110 win. Tuned with pyvrp_construction_budget=8 and plateaus_to_stop=20. Dispatched via solve_auto() (vanilla portfolio for N<100, warm variant for N≥100).

Evaluation tooling — what's built and how well it works

Parallel bench harness

bench/parallel.py wraps ProcessPoolExecutor with max_workers=4. Mandate doc at bench/PARALLEL_GUIDANCE.md. Working. Wall-time savings 3-4×.

Council shadow bench

svrptw/council/shadow_bench.py with two modes: run_shadow() (single-shot, 12 instances) and composability_run() (paired-seed 14th-arm test, 16 instances). Working after paired-seeding fix.

OOD validation protocol

Indices I=001-I=004 are held out from all tuning. v1 (tight capacity) + v2 (loose) provide regime cross-validation. Working. Cumulative 83/88 wins (94%) on truly held-out instances.

LLM operator proposer

svrptw/council/proposer.py, Gemini-direct. Prompt = seeds + rejection corpus + API cheat sheet ≈ 3200 tokens. Plumbing works but yield is poor: 25 proposals → 5 schema-pass → 0 production-validated.

Academic benchmark loaders

svrptw/io/solomon.py::load_solomon + Solomon/Homberger fetchers. Working. Verified by hitting published C101 optimum within 0.01%.

Multi-objective evaluator

svrptw/solvers/common/solution.py::evaluate with opt-in cost extensions (per_route_fixed_cost, underutil penalty, symmetry penalty). All gated default-zero for backward compatibility. Working; produces the structural advantage headline.
